# UniSync — Unified College Collaboration Platform

A professional frontend-only college collaboration portal extracted into a clean,
GitHub-ready project structure.

## Project Structure

```text
UniSync/
├── index.html
├── style.css
├── app.js
├── dashboard.js
└── README.md
```

## Included Modules

- Landing page
- Student / Faculty / Admin demo role switching
- Dashboard
- Kanban project workspace
- Real-time-style campus chat UI
- Academic resource vault
- Campus forum and discussions
- Clubs and events
- Notifications
- Global search
- Calendar
- Profile / role-based views
- Dark/light theme
- Responsive UI
- Toast notifications
- Interactive demo actions

## Run

No Node.js installation is required.

1. Extract the folder.
2. Open `index.html` in a browser.

For best results, use VS Code with Live Server.
